# Claude Design Skills Extraction

> Extracted from the uploaded HTML portfolio. This focuses on the design methodology and patterns rather than the implementation details.

## 1. Design Philosophy

- Design around a single immersive narrative.
- Every UI element reinforces the story.
- Interface feels like a cinematic product rather than a webpage.
- Minimal colors, maximum atmosphere.

---

## 2. Design System First

Always define reusable design tokens before building components.

```css
Colors
Typography
Spacing
Borders
Animation timing
```

Characteristics:
- Consistent variables
- Limited palette
- Reusable spacing scale
- Shared typography system

---

## 3. Typography Hierarchy

Uses three font roles:

- Display Font → Large headings
- Monospace → Technical labels, HUD, metadata
- Body Font → Readable content

Pattern:

Display
↓
Mono metadata
↓
Body copy

---

## 4. Story-Driven Sections

Each section is treated like a chapter.

Example structure:

Hero
↓

About / Dossier
↓

Experience / Missions
↓

Skills / Equipment
↓

Testimonials / Reports
↓

Contact

Every section has:
- Label
- Large title
- Supporting metadata
- Content block

---

## 5. Layered Visual Design

Instead of one background, combine multiple layers:

- Background color
- Noise / Grain
- Scanlines
- Gradients
- Overlay tint
- Grid
- Lighting
- Masks

This creates depth without heavy graphics.

---

## 6. Color Strategy

Very limited palette.

Primary background

- Near black

Primary text

- Warm white

Accent

- Green

Danger

- Red

Warning

- Amber

Use accents sparingly.

---

## 7. Premium Minimalism

Avoid:
- Large shadows
- Rounded cards everywhere
- Bright gradients
- Excessive decoration

Prefer:
- Thin borders
- Spacious layouts
- Large typography
- Contrast
- Precision

---

## 8. Grid-Based Layout

Everything aligns to a consistent grid.

Examples:
- 2-column layouts
- 3-column cards
- Equal spacing
- Responsive collapse

---

## 9. Cinematic Hero

Characteristics:

- Full viewport
- Video background
- Dark overlay
- HUD elements
- Large title
- Minimal text
- Scroll indicator

The hero tells the story immediately.

---

## 10. Motion Principles

Motion is functional.

Examples:

- Loading sequence
- Reveal animations
- Scan sweeps
- Progress bars
- Hover transitions

Avoid random animations.

---

## 11. Component Consistency

Every component follows:

Header
↓

Body
↓

Metadata
↓

Interaction

No component feels visually different.

---

## 12. UX Principles

- Immediate immersion
- Strong hierarchy
- Predictable spacing
- Minimal cognitive load
- Consistent interactions

---

## 13. Reusable Design Formula

1. Start with story
2. Build design tokens
3. Establish typography
4. Create grid
5. Layer backgrounds
6. Design reusable sections
7. Add purposeful motion
8. Maintain consistency
9. Keep color palette restrained
10. Polish interactions

---
